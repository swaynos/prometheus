# Project terms

| Term | Meaning |
| --- | --- |
| Candidate | The workspace submitted for independent verification. A manifest identifies its included files; it does not isolate them. |
| Evaluator | The Build child session assigned to assess a candidate and report results. |
| Origin session | The OpenCode session that requests verification. This is distinct from a browser origin. |
| Proxy session | A named, persistent proxy assignment. It is separate from an OpenCode session and a saved authentication record. |
| Generation | A version of a proxy session's assignment. Explicit rotation creates a new generation. |
| Authentication record | Private saved browser login state for approved origins. Association with a proxy session is explicit. |
| Handoff and handback | Transfer of browser control to the user and its explicit return to the agent. A separate login window is not the task browser. |
| Unresolved charge | A paid-task reservation without a trustworthy actual charge. It blocks new reservations until reconciled. |
